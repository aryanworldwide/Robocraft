RoboCraft — Robotics & AI for ICSE and ISC students

A complete companion for the CISCE Robotics and Artificial Intelligence syllabus, Classes 9 to 11. Most of it works offline, and there are no ads.

Download the Android app Source code on GitHub

What is inside

  • Every chapter as textbook notes with labelled diagrams, key terms and audio.
  • Board practice — chapter-wise MCQs, short and long answers with model answers, timed sample papers and PDF answer keys.
  • Circuit Lab (2-D) — wire an Arduino circuit and run your own sketch on a simulated board.
  • Robot Arena (3-D) — the same Arduino code drives a robot car: line follower, obstacle avoider, smart dustbin, maze and PID tuning.
  • 3-D Design Studio — solid modelling with holes and groups, real robot parts in true sizes, and STL export for 3-D printing.
  • Mechanism Lab — four-bar linkages, slider-crank, robot-arm kinematics and gear trains.
  • Practical file — CISCE-format assignments, an automatic variable description table and a printable PDF.
